# Łuk i Ziarno

Projekt koncepcyjny – marka fikcyjna

Identyfikacja wizualna fikcyjnej kawiarni z trzema wersjami logo i dziewięciostronicową księgą znaku.

## Overview

A concept for café identity, logo design, and brand guideline commissions. The monogram combines the silhouette of an entrance arch with a coffee bean.

![Primary logo](exports/logo-kolor.png)

## Files

- `source/` — three editable logo variants, favicon, and nine guideline spreads.
- `exports/` — PNG and PDF logo variants, PNG favicon, and the nine-page PDF guideline.
- `index.html` and `ksiega.html` — responsive gallery and guideline reader.

## Editing

Open the SVG files in Inkscape. Edit the paths and live text, then export the page in SVG, PNG or PDF. DejaVu Serif and DejaVu Sans are used for typography. CMYK values are reference conversions and should be profiled by the printer for production.

## Technology

Original SVG paths, HTML, CSS, Inkscape, and Poppler. No photographs or third-party artwork.
